# Kevin Leichen · Portfolio

Personal data science portfolio, Spanish by default with an English version at `/en/`. Built with [Astro](https://astro.build), deployed on Vercel.

## Run locally
```bash
npm install
npm run dev
```

## Add a project
Create `src/content/projects/es/<name>.md` and `src/content/projects/en/<name>.md` with the same `page` value in the frontmatter (it becomes the URL). Put images and embedded tools under `public/projects/<name>/`.
